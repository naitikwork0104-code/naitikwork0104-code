# 🚀 Featured Project

## 🔐 NeuroResonance

### Secure File Access & Approval Management Platform

A Flask-based secure file-access platform built around **controlled resource access and administrator approval workflows**.

**What I built:**

```text
User Request
     │
     ▼
Administrator Review
     │
 ┌───┴────┐
 ▼        ▼
Approve  Reject
 │
 ▼
One-Time Download Token
 │
 ▼
Server Validation
 │
 ▼
Time-Limited Secure Access
```

### Highlights

* 🔒 Administrator-controlled approval workflow
* 🎟️ Time-limited, one-time download tokens
* 🗄️ PostgreSQL + Supabase + SQLAlchemy
* 📧 Automated email approval/rejection workflow
* 🌐 Responsive frontend
* 🚀 Gunicorn production deployment
* ⚙️ Environment-based configuration
